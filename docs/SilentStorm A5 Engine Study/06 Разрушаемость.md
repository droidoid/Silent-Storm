# Разрушаемость зданий

← [[00 Главная]]

Визитная карточка игры. Главный вывод: обрушение — это **расчёт устойчивости конструкции**, а не симуляция твёрдых тел.

## Два слоя представления

**1. Решётка прочности** — `CBuildingGrid` (`Main/BuildingGrid.h`)

- `CArray3D<BYTE> net`: по одному байту прочности на узел.
- 4 вертикальных слоя на этаж: `PLANE_DIST = WALL_HEIGHT/4`, `WALL_HEIGHT = 2.5` (`Main/BuildingInfo.h`).
- Горизонтальный шаг — `MIN_NODE_DIST = FP_GRID_STEP`.
- 0 — узел разрушен. `N_INDESTRUCTIBLE` и `N_CELLAR` — неразрушаемые.

**2. Видимая геометрия**

- Здание собрано из фрагментов стен и объёмов (`SBuildFragment`, `CConstructionPart`), разбитых на мелкие куски.
- `SetSolidVisibleParts` / `SetVisibility` в `Main/MakeBuilding.cpp` прячут кусок, чей узел разрушен.
- Сетка пересобирается по частям `SPart` (этаж, x, y): `CBuilding::UpdateBuildingParts` в `Main/wBuilding.cpp`.

## Нанесение урона

- `CBuildingGrid::DamageSpot` вычитает прочность узла; на нуле вызывает `CBuildingSchema::Destroy`.
- `CBuildingGrid::Explode` бьёт по всем узлам в сфере, урон падает примерно как 1/d².
- Пули: `NRPG::CBuilding::ProcessAttack` (`Main/RPGBuilding.cpp`) находит узел по хэшу куска и применяет `CAttackPortion::CalcStructDmg` (`Main/RPGAttackMech.cpp`).
- Гранаты: `CWorld::AddGrenadeExplosion` → `CVoxelExplTracker` (`Main/wExplTracker.cpp`). Волна растекается по вокселям 0,2 м AI-геометрии, ограниченная объёмом.

## Расчёт обрушения — `CBuildingSchema`

Файлы: `Main/BuildingSchema.cpp`, `Main/rod.h`, `Main/RodJunction.h`.

- Схема — граф узлов `CJunction`, соединённых стержнями `CRod`. Строится из стыков кусков AI-геометрии (`MakeBuildingSchema`).
- `Recalc` выполняет три шага:
  1. **`ComputeStability`** — по этажам снизу вверх. Устойчивость идёт от вертикальной опоры (`UpdateVerticalStability`) и распространяется вбок функцией `Shoot()` в 8 направлениях.
  2. **`FindFree`** — оставшиеся неустойчивые узлы группируются и помечаются `FREE` или `UNSTABLE_NOTFREE`.
  3. **`ComputeMoments`** — нагрузка и изгибающий момент распространяются фронтом. У узла есть пределы `fUltimateMoment` и `fUltimatePressure` из материала (`SetDestroyLimits`).
- Узлы `FREE` разрушаются; перегруженные — через `IsBroken` / `IsLinkBroken`.
- Узлы на земле и стены подвала не разрушаются.
- `UpdateBuildingStability` повторяет `Recalc`, пока есть изменения.
- Отладочный просмотр схемы — `Main/BSchemaViewer.cpp`.

## Безнадёжно устарело

- Шейдеры ps1.x и ветки рендера под GeForce2/3.
- Скиннинг на CPU с MMX.
- Стенсильные теневые объёмы.
- Жёсткая привязка к MS SQL / ADO и MFC.
- Аллокатор с резервированием по фиксированному адресу.
- Lua 4.0.
- Генерация кода макросами IDE.

## С оговорками

- Иерархический поиск пути по зонам разумен, но Дейкстра без эвристики и пределы сетки (8 этажей) — наследие эпохи ([[10 ИИ и поиск пути]]).
- Монолитная DLL без границы «движок/игра» затрудняет вынос подсистем ([[01 Архитектура]]).

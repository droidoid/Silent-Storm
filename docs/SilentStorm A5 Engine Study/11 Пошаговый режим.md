# Пошаговый режим

← [[00 Главная]]

## Механизм

- `CTBSWorld` (`Main/wTurnBased.h`) — шаблонный класс со **стеком перехватов**.
- Стек пуст → игра идёт в реальном времени. Иначе ходит игрок с вершины стека.
- В стеке допускается не больше одного перехвата.
- `CWorld::IsTBSRealTimeModePossible` решает, можно ли вернуться в реальное время.
- Проверка `CheckRealTimeTurn` вызывается в конце каждого сегмента мира — см. [[01 Архитектура]].

## Перехват хода

- Срабатывание — `CWorld::CheckInterrupt`.
- Шанс — `CUnitMission::CalcInterruptProbability` (`Main/RPGUnitMission.cpp`): базовое значение плюс разница навыков `ST_INTERRUPT`, минус штраф за уже потраченные ОД, в пределах 5–95 %.

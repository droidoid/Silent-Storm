# Инфраструктура

← [[00 Главная]]

## Память

- Статическая библиотека `MemoryMngr` (`DumbPow2Alloc.cpp`) подменяет глобальные `operator new/delete` и передаёт вызовы в DLL.
- `MemoryMngrDll/FastPow2Alloc.cpp` резервирует 512 МБ по фиксированному адресу `0x08000000` и делит их на 16 пулов по степеням двойки. Память коммитится по 64 КБ, есть списки свободных блоков и спин-лок.
- Запросы больше 32 КБ и вся отладочная сборка идут в `malloc`.
- Трассировка утечек (`Trace.cpp`: `DebugRegister`, `DumpMemoryStats`) написана, но вызовы закомментированы.

## Файлы — `FileIO/`

- Иерархия потоков `CDataStream`: память, файл, буферизованный, битовый.
- Паки `.res` — см. [[13 Пайплайн ассетов]].
- Сериализация — см. [[14 Сериализация]].

## Ввод — `Input/`

- DirectInput8: мышь, клавиатура, джойстики.
- Именованные команды с секциями (`Input/Bind.h`: `CBind("exitgame")`, `SBind`, типы «слайдер» и «событие»), консольные `bind` / `unbind`.

## Звук

- `FModSound/FMSound.cpp` (727 строк) — обёртка над FMOD 3 (`FSOUND_*`): 2D/3D-сэмплы, потоки.
- Поверх — `Main/Sound.cpp` (`CSoundScene`), `Main/SoundEffect.cpp`.
- **Заглушки нет.** SDK FMOD в репозитории отсутствует, есть только `bin/fmod.dll` и `bin/FMODWrapper.dll`.
- Инициализация пропускается при `sound_mode = 0`; иначе при сбое `Game/Main.cpp` показывает «Failed to initialize FMod».

## Видео

- Bink в исходниках не упоминается нигде. В `bin/` есть только `binkw32.dll`.

## Прочее

- Консоль, переменные, события — в [[01 Архитектура]].
- `Image/`, `libpng/`, `zlib/` — работа с изображениями и сжатием.
- `Scintilla/` — редактор текста для [[16 Редактор карт]].

Что из этого мешает сборке — в [[18 Сборка и состояние]].

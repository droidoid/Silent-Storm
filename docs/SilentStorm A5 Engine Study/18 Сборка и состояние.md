# Сборка и состояние

← [[00 Главная]]

## Расхождения со стартовыми сведениями

> [!warning] Три поправки к описанию из задания и README
> 1. **Direct3D 9, а не 8.1.** `Main`, `Game`, `MapEdit` линкуют `d3d9.lib` / `d3dx9.lib`; в `Main/Gfx.cpp` — `Direct3DCreate9`. На d3d8 остались только старые конфигурации `GfxTest`, `ShaderCompiler` и прототип `Soft/Monster`.
> 2. **VS .NET 2002, а не 2003.** `A5.sln` — «Format Version 7.00»; рантаймы VC7.0 лежат в `Tools/`.
> 3. **`OpenDynamix` — сторонний ODE и игрой не вызывается** — см. [[07 Физика и баллистика]].

## Что на месте

- Все исходники: 1457 из 1457 файлов, перечисленных в `.vcproj`, существуют (`Main` — 589, `MapEdit` — 392).
- Lua 4.0 (`Script/`), Scintilla, zlib, libpng.
- STLport 4.5.2 с готовыми библиотеками — `Soft/SDK/stlport`.

## Чего не хватает для сборки

| Что | Комментарий |
|---|---|
| DirectX 9 SDK | заголовки и `d3dx9` |
| FMOD SDK | `fmod.h`, `fmodvc.lib`; есть только DLL |
| LifeStudioHeadAPI | заголовки, `.lib`, `GDPFile.lib`; есть только DLL |
| s3tc | `s3tc.h`, `s3tc.lib` |
| Maya SDK | пути `C:\AW\Maya3.0`, `C:\AW\Maya4.0` зашиты; готовые `.mll` есть в `Tools/` |
| ADO | `#import` по абсолютному пути к `msado15.dll` |

Также зашиты диск `W:\` и устаревший путь к STLport 4.0 в `MapEdit`.

## Заглушки

- Единственная настоящая заглушка — `ADOFake/BasicDBfake.cpp` (слой базы без ADO) — см. [[12 База контента]].
- Для FMOD заглушки нет, для Bink нет вообще никакого кода — см. [[17 Инфраструктура]].

## Что говорят README

- Исторический релиз «как есть» под некоммерческой лицензией Nival.
- FMOD и Bink не включены и требуют замены.
- Запуск `bin/Game.exe` на современных Windows проблемен.

## Итог

Собрать «как есть» сегодня нельзя. Нужен перенос на современный компилятор, замена FMOD и LifeStudio, правка путей. Код при этом полный.

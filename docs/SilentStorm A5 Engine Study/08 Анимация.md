# Анимация

← [[00 Главная]]

## Данные

- Кость `SBone`: имя, родитель, позиция, кватернион, масштаб (`Main/GAnimFormat.h`).
- Поза `SSkeletonPose = vector<SBonePose>` (`Main/GSkeleton.h`).
- Клип `CFileAnimationInfo`: заголовок (fps, длина, число корневых костей, костей «только поворот», костей со сменой родителя, костей с масштабом) и массивы ключей `keysRoots`, `keysBones`, `keysAddBones`, `keysMSR`.

## Блендинг — дерево узлов

Файлы `Main/GAnimation.h/.cpp`. Фиксированного числа слоёв нет: дерево произвольной глубины из попарных узлов `CAnimator`.

| Узел | Назначение |
|---|---|
| `CASequence` | проигрывание клипа |
| `CAInterpolator` | переходы (`AddTransit`: линейный, синус, парабола) |
| `CAAdder` | аддитивное смешивание с весом |
| `CASubtractor` | вычитание позы |
| `CATurnBody` | поворот корпуса |
| `CAIK2Chain` | двухзвенная IK |
| `CASmartAimer` | прицеливание |
| `CABoneFilter` | маска костей |
| `CAPoseMemorizer` | запоминание позы |
| `CParticleSkeleton` | рэгдолл — см. [[07 Физика и баллистика]] |

- Корень — `CSkeletonAnimator`, узел `CFuncBase<SSkeletonPose>` из [[02 Dataflow DG]].
- `CBind` (`Main/GBind.h`) превращает позу в матрицы.

## Скиннинг

- На **CPU**, в `Main/GCombiner.cpp`: `TransformPosition`, `SingleSkinTransform`, `CalcSkinnedNormal`.
- До 4 весов на вершину; есть MMX-путь (`CMMXAnimationMatrices`) для 1–3 весов.
- В шейдерах скиннинга нет — см. [[05 Шейдеры]].

## Экспорт из Maya

- `A5ExportModel/` — транслятор файлов Maya (`pluginMain.cpp`, `A5ExportModel::writer`).
- Опции: mesh / skin, ai_mesh / ai_skin, animation, skeleton, particles, light, fps, start/end, scale.
- Функции: `ExportMesh`, `ExportSkin` (веса и отдельный файл привязок), `ExportAIMesh`, `ExportSkeleton`, `ExportAnimation`, `ExportParticles`, `ExportLight`.
- Выход — чанковые бинарные файлы без расширения, имя — числовой id ресурса. Сетки по материалам: `nFile + (nMat<<16)`.
- Полный путь данных — [[13 Пайплайн ассетов]].

Лицевая анимация — отдельная заметка: [[09 Лица LifeStudio]].

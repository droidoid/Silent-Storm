# ИИ и поиск пути

← [[00 Главная]]

## AI-геометрия и BSP

- `CGeometryInfo` (`Main/aiObject.h`) — набор кусков; у каждого точки, рёбра, объём, стыки и BSP-деревья.
- Соответствует папкам данных `Complete/AIGeometries` и `Complete/AIBSPTrees`.
- `CTwoBSPTrees` хранит деревья «открыто/закрыто» для дверей и по стадиям разрушения (`Main/aiObjectLoader.h`).
- Если дерева нет в данных, `CCollider::AddConvexHull` строит его на лету.
- Данные генерирует редактор — см. [[16 Редактор карт]].

## Поиск пути

- Алгоритм — **Дейкстра с корзинной очередью** (`CWaveCountCostsMajor`, `Main/aiWaveSearch.h`). Эвристики нет, это не A*.
- Пространство состояний `SPathPlace` (`Main/aiPosition.h`): тайл x/y, слой, направление, поза, флаг движения.
- Тайлы `STile` (`Main/aiGrid.h`) хранят флаги проходимости по позам и высоту.
- Пределы: `N_MAX_FLOORS = 8`, `N_MAX_LAYERS_PER_FLOOR = 4`, высоты перелезания 0,55–2,8 м. Лестницы учитываются отдельно.
- Проходимость считает `CPassCalcer` по геометрии коллизий.
- Иерархия: `CColouredWaysCalcer::CalcBestWays` сначала ищет маршрут по «цветным» зонам `SZone`, он ограничивает точный поиск (`SPathFinder2::FindPath` в `Main/aiPath.cpp`).

## Вейпоинты

- `CWaypoint` (`Main/aiWaypoint.h`) — скриптуемая патрульная точка с командами GOTO / POSE / WAIT / DIR.
- `SRoute` — список точек; маршруты юнита хранит `CUnitAIInfo`.

## Тактика

Жёсткие приоритеты с небольшой оценкой позиций, не планировщик.

- `CAITacticalCommander` (`Main/aiTacticalCommander.cpp`) ведёт юнитов по очереди через квантуемые задачи `CAIJob` и всегда назначает `CAILogicAttack` (`Main/aiCompoundAction.cpp`).
- `CAIFindGoodPlacesJob` перебирает точки по пути к врагу в пределах 12 ОД и выбирает лучшую по укрытию (`GetCoverForFixedUnit`).
- `CAIChoosePlaceForActionsJob` проверяет `CanDo` / `ComparePlaces` для каждого действия.
- `MakeDecision` пробует по порядку: перезарядка → ракета → граната → выстрел → сближение.
- Критерии оценки в `Main/aiCriterion.h` целиком закомментированы.

## Зрение и слух

- `CVisionTracker::IsCubeVisible` (`Main/RPGVision.cpp`): дальность 20 м, цель видна при 4 из 9 лучей со смещением.
- Наборы видимости игрока — `CPlayerBaseVision` (`Main/wVision.h`).
- Слух — проверка расстояния и бросок вероятности (`CUnitMission::CanHearSound`).

## Тестовые стенды

- `AItest/` — консольный прототип трассировщика луча с интервалами входа/выхода.
- `AIPathTest/` — MFC-приложение поиска пути в 2D-мире с полигональными препятствиями.

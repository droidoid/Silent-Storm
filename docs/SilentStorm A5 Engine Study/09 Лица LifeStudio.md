# Лицевая анимация (LifeStudio)

← [[00 Главная]] · часть [[08 Анимация]]

Используется сторонняя закрытая библиотека **LifeStudio:Head**. Её заголовков и `.lib` в репозитории нет, есть только DLL в `bin/` и `Tools/` — см. [[18 Сборка и состояние]].

## Конвертер — `LSConverter/LSConverter.cpp`

| Ключ | Действие |
|---|---|
| `-g` | файл головы GDP → игровой формат (`OutputInGameFormat`): потоки аниматора по объектам, UV, копии вершин, нормали, запечённая TGA-текстура, `.mat` / `.tex` |
| `-s` | обёртка файла последовательности MMS |
| `-i` | вывод сведений |
| `-o` | экспорт в OBJ |

## В игре

- `Main/LSHead.h/.cpp`: `CHeadAnimator::Recalc` вызывает `ISequencer::RenderMacroMuscles` → `IAnimator::ComputePhysics` → `Process`.
- Результат — позиции вершин на CPU каждый кадр и пересчитанные нормали. Загружается также `tree.mma`.
- `CHead` превращает это в геометрию сцены (создаётся в `Main/GView.cpp`).
- `CHeadsController` (`Main/LSController.h`) проигрывает последовательности для юнитов.
- `CHeadAnimator` — узел [[02 Dataflow DG]].

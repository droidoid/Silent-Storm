# Сцена и рендер

← [[00 Главная]]

> [!warning] API
> Код вызывает **Direct3D 9** (`Direct3DCreate9` в `Main/Gfx.cpp`), хотя шейдеры — уровня DX8. Подробнее в [[18 Сборка и состояние]].

## Сцена

- Интерфейс `IGScene` (`Main/GScene.h`), реализация `CGScene` (`Main/GSceneInternal.h/.cpp`).
- Пространственная структура — свободное **октодерево**: `CVolumeNode : COcTreeNode` (`Main/OcTree.h`).
- В каждом узле — корзины `SPerMaterialHolder` для статики и динамики: transparent / occluder / normal / normalLM / alien.
- Типы объектов: `CSimplePart`, `CDiscretePart`, `CDynamicPart`, `CAnimatedPart`, `CDynamicGeometryPart`.
- Группировка битовой маской (`SGroupInfo`, `N_MASK_*`); этажи — биты `0x0fff`.
- Порталов нет. BSP используется только ИИ и коллизиями — см. [[10 ИИ и поиск пути]].
- Отсечение невидимого — программный иерархический Z-буфер `CHZBuffer` в `Main/GShadowVolume.cpp` (`MakeInvisibleElementsList`).

## Батчинг

- Части сливаются в общие буферы вершин и индексов: `CPerMaterialCombiner`, `CVBCombiner`, `CIBCombiner` (`Main/GCombiner.h`).
- `CSceneFragments` (`Main/GRenderCore.h`) группирует фрагменты по материалу, лайтмапе и ambient.

## Список операций

- Абстракция — `CRenderCmdList::SOperation`: код операции `ERenderOperation` (около 90 штук), проход, код стенсила/блендинга, «регистр» назначения (render target).
- `Execute` в `Main/GRenderExecute.cpp` сортирует операции (`SCompareOps`): проход → регистр → операция → состояние → параметры → фрагмент.

## Порядок кадра: `CGScene::Draw`

1. метки отсечения (HSR);
2. `MakeRenderList`;
3. `ILight::Render` для каждого источника, многопроходно — [[04 Свет и тени]];
4. туман и зеркала;
5. постобработка;
6. линии;
7. прозрачное — `CTransparentRenderer` с поразрядной сортировкой по глубине (`Main/GTransparent.cpp`);
8. выделение.

## Пути рендера по железу

- `ERenderPath` в `Main/GRenderModes.h`: RP_TNL, RP_GF2, RP_GF2_CL, RP_GF3_CL и другие.
- Уровень железа — `GetHardwareLevel()` в `Main/GfxRender.cpp`: TnL / GeForce / GeForce3 / Radeon с ps1.4.
- Шейдеры и их запасные варианты — [[05 Шейдеры]].

## LOD

- Есть LOD лайтмап (`N_LM_LODS = 5`, `Main/GGeometry.h`) и узел детализации текстуры рельефа (`Main/GTerrainTexture.h`).
- LOD геометрии моделей не найден — см. [[21 Не подтверждено]].

## Частицы

- Данные — запечённые ключи `SParticle` (позиция, поворот, масштаб, цвет, спрайт) в `Main/GParticleFormat.h`, экспорт из Maya.
- Аниматоры: `CParticleAnimator`, `CExplosionAnimator`, `CGrassAnimator` (`Main/GParticles.h`).
- Геометрия: `CShaderParticlesGeometry` или `CTnLParticlesGeometry` (`Main/GSceneParticles.h`). Освещённые частицы берут свет из лайтмапы частиц.
- `Soft/Andy/Jan03/pd/` (ParticleDynamics) — **не редактор эффектов**, а MFC-прототип физики точечных масс и связей.

## Декали

- `CDecalsManager`, `CDecalTarget` (`Main/GDecal.h`).
- `CPerPolyDecalGeometry`, `CExplosionDecalGeometry` (`Main/GDecalGeometry.cpp`) обрезают треугольники цели четырьмя плоскостями и строят новую геометрию.

## Текст

- `FontGen/FontGen.cpp` растеризует TrueType через GDI в текстуру и таблицу `CFontFormatInfo` (UV, ширины ABC, кернинг).
- В игре — `CTextFormater` (`Main/GText.cpp`) с тегами `TagFont`, `TagColor`.

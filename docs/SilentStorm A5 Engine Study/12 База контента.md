# База контента

← [[00 Главная]]

SQL-база — **единственный источник истины** для всех метаданных контента, включая карты.

## Таблицы

`DBFormat/DataFormat.cpp` регистрирует 130 таблиц макросом `REGISTER_DATABASE_CLASS(id, "Таблица", Класс)`.

| id | Таблица |
|---|---|
| 1, 2, 3 | Models, Animations, Textures |
| 9, 10, 13 | Materials, Geometries, Skeletons |
| 11 | Units |
| 4, 5 | Templates (карты), TemplVariants |
| 7 | FinalElements (расставленные объекты) |
| 23, 24, 30 | Walls, Floors, Rooms |
| 46, 47 | ConstructionParts |
| 60 | Waypoints |
| 79–84 | Scenario* |
| 97 | Dialogs |
| 45, 100 | Strings, TranslatedStrings |
| 43, 44 | UIControls, UIContainers |
| 0xE00000xx | RPG*: оружие, броня, предметы, перки |

Связи «многие ко многим» — `REGISTER_DATABASE_RELATION` (например, `RPGPers2Scripts`).

## Отображение таблиц на классы

- Написано **вручную**, не генерируется.
- Каждый класс `NDb::C*` наследует `CDBRecord` (`ADOImport/BasicDB.h`) и имеет `Import()` с вызовами `NDatabase::ImportField("Колонка", &поле)`.
- Колонки-ссылки именуются `XxxID` и разрешаются в `CPtr<T>`.
- Таблицы связей — `ImportRelation`.

## Подключение

- Строка в `ADOImport/BasicDB.cpp` (`GetDBConnectionStr`): драйвер SQL Server, сервер `a5server`, база `A5GAME`.
- Соответствует файлу `Data/A5GAME_Data.MDF`. `Data/game.mdb` — более старый вариант на Access.

## Три реализации доступа

| Проект | Роль |
|---|---|
| `ADOImport` | настоящий импорт через ADO (`msado15.dll`): `SELECT * FROM <таблица>`. Два прохода: создать записи и связи, затем `Import()` каждой |
| `ADOFake` | заглушка с тем же API (`ADOFake/BasicDBfake.cpp`): импорт — `ASSERT(0)`, работают только регистрация и `Serialize` |
| `DataImport` | утилита: импорт + `NDb::BuildMapLinks` + запись `game.db` |

## `game.db`

- Это дамп всех таблиц (хэш-карты записей) через `CStructureSaver` — см. [[14 Сериализация]].
- Пишет `DataImport/DataImport.cpp` (ключи `-dbserver`, `-translate`) в `w:\Complete\game.db`.
- Игра читает его в `WinMain` до инициализации графики — см. [[01 Архитектура]].
- Редактор `game.db` не читает, а ходит в SQL напрямую — см. [[16 Редактор карт]].

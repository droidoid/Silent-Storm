# Пайплайн ассетов

← [[00 Главная]]

## Главное правило

**Имя файла ресурса = числовой id записи в базе.** Расширений нет.

- Папка на тип ресурса: `Complete/Geometries/1000`, `Complete/Textures/1001`.
- Варианты кодируются старшими битами: `(i<<16)+nID`, `id|0x01000000` для копии DXT-текстуры в 8888.
- `Main/GResource.cpp` сначала ищет файл в паке `<Тип>.res`, иначе читает отдельный файл `"%s\\%d"`.
- Обращения: `CFileRequest("Geometries", id)` в `Main/GObjectInfo.cpp`, `"Textures"` в `Main/GTexture.cpp`, `"Buildings"` в `Main/BuildingInfo.cpp`, `"Terrain"` в `Main/MapBuildTerrain.cpp`.

## Из Maya в игру

1. Художник кладёт исходник в `W:\Art\ForComplete\Models\`.
2. Редактор (`MayaExport` в `MapEdit/Export.cpp`) пишет `maya.mel`: загрузка плагина `A5ExportModel.mll` и экспорт с опциями.
3. `maya.exe` запускается в batch-режиме.
4. Плагин `A5ExportModel/` пишет файлы в `Complete\Geometries\<id>`, `Binds\`, `Locators\` — подробности в [[08 Анимация]].
5. Редактор обновляет таблицы в памяти: `NDatabase::Refresh<NDb::CGeometry>()`.

## Текстуры

- `TexConv/main.cpp`: тип (`-t` Ordinary / Bump / Transparent / LinearPicture), формат (`-f` 8888 / 4444 / 565 / 1555 / DXT1–5), мипы, размер карты нормалей.
- Выход — собственный формат MMP (`mmpFormat.h`, заголовок «MMP\0») или DDS.
- Редактор генерирует `texture_export.bat` из колонок базы (`ExportTextures` в `MapEdit/Export.cpp`).
- `TexMipStrip/` отрезает старшие мипы до заданного размера.

## Паки `.res`

- Сборщик `PkgBuilder/PkgBuilder.cpp` вызывает `UpdateFilesPackage` (`FileIO/FilesPackage.cpp`).
- Формат: сигнатура `0x95938921`, смещение заголовка, файлы подряд, в конце — таблица id → {начало, длина} и времена файлов через `CStructureSaver`.
- Не zip, без сжатия. Обновление инкрементальное, принимаются только числовые имена.
- `Complete/makeCurrent.bat` запускает `DataImport` и по одному `PkgBuilder` на папку.

| Папка | Содержимое |
|---|---|
| `Jan03` | основное дерево: 1381 файл `.cpp/.h`, около 321 тыс. строк; плюс `pd/` (ParticleDynamics) |
| `Oct02/src` | только `Main`, плоская папка: 564 файла, около 146 тыс. строк |

## Oct02 → Jan03 (сравнение `Main` по именам файлов)

- Общих файлов 471; только в Jan03 — 121; только в Oct02 — 93.
- **Появилось в Jan03:** привязки Lua (`Script*.cpp`), перки (`RPGPerk*`), сохранения (`iSaveManager`), генерация персонажа и лица (`iCharGen`, `iFaceGen`), декали и постобработка (`GDecal`, `GPostProcessors`), `PhCollider`, маршруты ИИ (`AIRoute`, `AILocker`, `AIPassCalcJob`), мины, зрение, группы (`wMine`, `wVision`, `wUnitGroup`), `SoundEffect`.
- **Ушло:** файлы редактора (`Wysiwyg*`, `ME*`, `*Undo`) переехали в `MapEdit`; старые модули UI и `AIVoxel` исчезли.

## `Soft/Monster`

- Ранний **прототип на VC6**, не параллельная ветка: 104 файла, около 13,7 тыс. строк, проекты `.dsp/.dsw`, Direct3D 8.
- В логах сборки пути `W:\Soft\Monster` и `c:\home\A5\Game` — тот же проект A5.
- `game/readme.txt` — ранний список задач.
- Файлы без аналогов в Jan03: `GFormat`, `GScene`, `GSceneGraph`, `iInput`, `RPGMission`.
- `Monster/A5ExportModel` — 2,6 тыс. строк под Maya 3.0; в Jan03 — 8,1 тыс. под Maya 4.0, добавлены частицы и AI-сетки.

## `Soft/Andy/Apr03/p2pa7` — сеть

- Консольное приложение (`P2P_A7.sln`).
- UDP, собственный слой подтверждений (`NetAcks`), логин, широковещательный поиск серверов, P2P-трекер (`CP2PTracker`), интерфейс `NNet::IA4NetDriver`.
- **В игру не интегрировано:** в Jan03 нет ни ссылок на него, ни сокетов.

## Прочее в `Soft/`

- `Soft/SDK` — только STLport.
- `Soft/Serialize7`, `Soft/serialize.dsm` — макросы генерации сериализации, см. [[14 Сериализация]].
- `Soft/tt` — резервная копия базы SQL Server (4,6 МБ).
- `Soft/Bandures` — один установщик.

## Корень репозитория

- `bin/` — готовые `Game.exe`, `MapEdit.exe`, утилиты, DLL FMOD и Bink; также дистрибутив MySQL и серверы EthServer / MasterServer.
- `Versions/Current` — сборка для разработчиков и модов, август 2003.
- `Complete/` — игровые данные, `Data/` — базы, `Tools/` — утилиты и плагины Maya.
- `cfg/`, `scripts/` — конфиги и служебные скрипты MySQL, к игре не относятся.

См. также: [[18 Сборка и состояние]].

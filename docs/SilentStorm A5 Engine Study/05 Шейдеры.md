# Шейдеры

← [[00 Главная]] · часть [[03 Сцена и рендер]]

## Исходник

Все шейдеры лежат в одном текстовом файле `Main/GfxShaders.txt`.

- Секция `[VS]` — макроассемблер вершинных шейдеров с `proc`, `func`, `locals`.
- Каждый блок `[PS] имя` содержит:
  - код ps.1.1;
  - необязательный вариант `[PS14]` для Radeon;
  - `[RS]` — render states;
  - `[TSS]` — texture stage states, то есть **запасной вариант на fixed-function**.

## Компиляция

- Инструмент — `ShaderCompiler/ShaderCompiler.cpp`.
  - `CVSCompiler::GenerateShader` выдаёт vs.1.1 со строками `dcl_*`.
  - `CompileShader` вызывает `D3DXAssembleShader`.
  - `WriteResult` пишет `GfxShaders.h/.cpp` с массивами байт-кода `vsAllShaders` и `psAllShaders` (структуры `SVShader`, `SPShader`).
- Запускается как custom build step проекта `Main.vcproj`: шейдеры вкомпилированы в DLL.

## В игре

- `SetPixelShader` в `Main/GfxRender.cpp` при отсутствии пиксельных шейдеров применяет состояния `[TSS]`.
- Скиннинга в вершинных шейдерах нет — он на CPU, см. [[08 Анимация]].

## Оценка

Идея «шейдер как данные с компиляцией на сборке» жива; сами ps1.x и ветки под GeForce2/3 устарели — см. [[20 Что можно взять]].

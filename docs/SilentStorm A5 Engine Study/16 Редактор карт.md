# Редактор карт (MapEdit)

← [[00 Главная]]

Около 73 тыс. строк, 392 файла в проекте.

## Каркас

- MFC MDI (`CTEditApp`), плюс Stingray Objective Toolkit (`MapEdit/StdAfx.h`) и Scintilla для редактора Lua.

## Возможности

| Область | Файлы |
|---|---|
| Рельеф: высоты и пятна текстур | `TerrainLayer`, `WysiwygTerrain`, `WysiwygSphereHMap`, `TerrSpot*` |
| Объекты и юниты | `FinalElem`, `Placement`, `WysiwygObjectSel`, `WysiwygUnitSel`, `UnitDB` |
| Конструктор зданий: стены, полы, комнаты, подвалы, лестницы | `WallsLayer`, `FloorLayer`, `RoomsLayer`, `CellarLayer`, `PlacementBuilding`, `PiecesEditDlg` |
| Вейпоинты и маршруты | `WaypointDlg`, `WysiwygRoute` |
| Скрипты Lua | `LuaEditor`, `ScriptEditDlg` |
| Сценарии, в том числе через XLS | `ScenarioView`, `ScenarioXLS` |
| Редактор UI | `UIView` |

Также: дипломатия, карты глав и глобальная карта, материалы, камеры, товары магазина.

## Что переиспользует из движка

- `CGameView::SetGameWnd` (`MapEdit/GameView.cpp`) вызывает `NGScene::AddResourceDir`, `NGfx::Init3D`, `NInput`, `NSound`. То есть тот же рендер и та же сцена, встроенные в окно MFC — см. [[03 Сцена и рендер]].
- Использует цикл интерфейсов игры: `CIMapEditor : NMainLoop::IInterfaceBase` (`MapEdit/iMapEditor.cpp`) — см. [[01 Архитектура]].
- В коде `Main` есть ветки `#ifdef _MAPEDIT` (`GResource`, `GTerrainTexture`, `iMission`).

## Формат карты

- Карта — **записи в базе**, не файл: `CTemplate` → `CTemplVariant` (прямоугольники, объекты, юниты, вейпоинты, скрипт, музыка, дипломатия). Строки `FinalElements` хранят модель, позицию, поворот, этаж, масштаб.
- Производные бинарные данные пишет `MapEdit/MESerialize.cpp`: `Terrain\<id>`, `Buildings\<id>`, `Waypoints\<id>`.

## Работа с базой

- Пишет в SQL напрямую: шаблоны ATL OLE DB (`MapEdit/db.cpp`, `dbDefs.h`) и сырой `INSERT INTO` (`FinDBCmd.cpp`). Имя сервера — из реестра, по умолчанию `a5server`.
- Читает через собственную копию ADO-слоя (`MapEdit/BasicDB.cpp`), `game.db` не использует — см. [[12 База контента]].

## Экспорт

- Запуск Maya в batch-режиме — см. [[13 Пайплайн ассетов]].
- Генерация данных ИИ: `MapEdit/ExportGeometry.cpp` строит BSP в `AIGeometries\<id>`, `ExportAIDoors.cpp` — `AIBSPTrees\<id>` (см. [[10 ИИ и поиск пути]]).

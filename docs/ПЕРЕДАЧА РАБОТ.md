## 1. Цель проекта

Забрать из игры Silent Storm (Nival, 2003) **все технические решения, механики и приёмы ИИ** и повторить их на другом движке **максимально близко и с минимальными затратами**.

Критерии, которые владелец сформулировал явно (это важно, по ним уже были ошибки):

- Независимость нужна **только от Nival**. Любой движок допустим, включая Unreal и Unity. Отчисления допустимы. Мультиплатформа допустима.
- Движки сравниваются по тому, **сколько готового они дают и сколько стоит дописать остальное**, а не по чистоте лицензии. Первая редакция сравнения ошиблась именно здесь.
- Юридическая сторона переноса идей — закрытый вопрос. Владелец считает риск нулевым и не хочет к нему возвращаться.
- Сборка Silent Storm в этом репозитории — **образец и эталон для проверки**, а не продукт. Пройти кампанию или совпасть с релизом до мелочей — не цель.

## 4. Что не закончено

### 4.1. Прототип для выбора движка — не начат

Это главный следующий шаг. Подробно — в `23 Выбор движка.md`, раздел «Что решает прототип». Один и тот же опыт на одном здании из двух–трёх тысяч блоков: сколько стоит убрать сотню кусков за шаг и перерисовать блоки; как ведут себя свет и тени при обрушении, когда в помещениях 30–50 источников; во что обходится инструмент «нарисовать стену по сетке»; как быстро проверяется правка в ядре. Порядок решения: Unreal 5 справился с удалением кусков и светом — выбор сделан; не справился с удалением, но справился со светом — тот же опыт на Unreal 4.27; не справился со светом — на Unity 6.

### 4.2. Найдено и не исправлено: в каталог запуска копируются старые скрипты

Найдено при разборе `Кампания 2`, проверено по файлам. Исправление не делалось, потому что проверить его можно только запуском игры.

- `make_run_dir.cmd` копирует `Complete\Scripts\*.l`. Это строку добавил я при исправлении ошибок Lua.
- `Common.l` в `Complete\Scripts` старше релизного `Versions\Current\scripts\Common.l`. В старом файле `DelayGameStart()` вызывает `DelayGameStartEx()`, а `StartGame()` — `StartGameEx()`. Обе функции определены только в релизном файле. Игра под этими именами ничего не регистрирует: из кода доступны только `c_DelayGameStartEx` и `c_StartGameEx`.
- `DelayGameStart` вызывают 33 скрипта в базе контента (таблица `Scripts`). По коду их сценарий должен оборваться с ошибкой Lua в начале миссии; на живой игре не проверено. Учебная миссия ошибок не давала.
- Другие отличия старого `Common.l`: условия в функциях ожидания (`UnitCanFight`, `RouteIsFinished`) записаны иначе; номер текста диалога ухода из зоны 17041 вместо 16837; нет `DividedDeployDemo`. Остальные три файла (`Constants.l`, `Hint.l`, `TriggersManager.l`) совпадают.
- **Предлагаемое исправление:** копировать `Versions\Current\scripts\*.l`. Проверка — один согласованный запуск миссии, сценарий которой вызывает `DelayGameStart`.

### 4.6. Редактор карт отложен

Попытка установить SQL Server 2008 R2 Express остановлена: нет прав администратора, система ждёт перезагрузки, диски NVMe (возможна проблема размера сектора). В `Tools/SQL2K/` лежат файлы самого SQL Server 2000 — не проверялись. Устройство редактора описано в спецификации `Карта 2 — Редактор карт`.

## 6. Правила работы с владельцем

Сложились за эту сессию, нарушение каждого уже стоило времени:

- **Не запускать игру и редактор на рабочем столе без согласия на каждый запуск.** Запущенная игра перехватывала мышь владельца, а рабочий стол общий с другими проектами. Если запуск согласован — только через `run_game.ps1` с ограничением по времени; заранее сказать, сколько он продлится; ничего не оставлять работающим.
- **Сначала расследование по коду, потом правка.** Никаких экспериментов «попробую и посмотрю» на живом рабочем столе.
- **Документация должна быть видна из основной документации и на GitHub.** Новые документы — ссылка из `docs/README.md`; ссылки и картинки в обычном Markdown, не `[[...]]` и не `![[...]]`.
- **Писать по-русски простым языком,** с примерами; в отчётах не скрывать непроверенное.
- **Коммиты — в `main`, отправка — когда владелец просит.**
- Снимки экрана — только окна игры, не всего рабочего стола (однажды в снимок попали окна других сессий владельца).

# Задание для агента: прогон замеров на машине с видеокартой

← [Прототип](../README.md)

Ты работаешь на машине владельца проекта: Windows, видеокарта RTX 3090, установлен Unreal Engine 5.8. Нужно забрать свежий код из git, один раз запустить готовый скрипт замеров и убедиться, что результаты ушли в git. Работа механическая: скрипт всё делает сам, от тебя нужны проверки до и после.

Отвечай владельцу по-русски.

## Чего делать нельзя

- **Не правь код и скрипты.** Если что-то не собирается или падает, остановись и покажи владельцу вывод. Чинить будут на сервере сборки.
- **Не меняй настройки системы:** схему питания, драйверы, параметры Windows. Скрипт сам запишет схему питания в результаты, менять её не надо.
- **Ничего не устанавливай и не скачивай без согласия владельца.** Если чего-то не хватает, скажи, чего именно, и спроси.
- **Не запускай прогоны параллельно** и не запускай скрипт второй раз, пока первый не закончился.
- **Не удаляй ничего** за пределами папок `prototype\ue5\Binaries`, `prototype\ue5\Intermediate` и `prototype\ue5\Saved`.

## Шаг 1. Проверь, что всё на месте

Выполни проверки и покажи владельцу итог одной короткой таблицей. Если хоть одна не прошла, остановись и спроси.

1. **Git.** `git --version` отвечает.
2. **Репозиторий.** Найди на диске клон `https://github.com/droidoid/Silent-Storm`. Если его нет, спроси владельца, куда клонировать, и клонируй ветку `main`. Дальше эта папка называется `<репозиторий>`.
3. **Движок.** Найди папку Unreal Engine 5.8. Обычно это `C:\Program Files\Epic Games\UE_5.8`. Признак правильной папки — в ней есть оба файла:
   - `Engine\Build\BatchFiles\Build.bat`
   - `Engine\Binaries\Win64\UnrealEditor.exe`

   Если не нашёл, спроси у владельца путь. Дальше эта папка называется `<движок>`.
4. **Версия движка.** Открой `<движок>\Engine\Build\Build.version`. Должно быть `"MajorVersion": 5` и `"MinorVersion": 8`. Запиши `PatchVersion`: на сервере сборки он равен 4. Если версия не 5.8, остановись.
5. **Компилятор.** Установлена Visual Studio 2022 с набором «Разработка игр на C++». Проверка: существует `C:\Program Files (x86)\Microsoft Visual Studio\Installer\vswhere.exe`, и команда ниже выводит путь.

   ```
   & "C:\Program Files (x86)\Microsoft Visual Studio\Installer\vswhere.exe" -latest -products * -requires Microsoft.VisualStudio.Component.VC.Tools.x86.x64 -property installationPath
   ```
6. **Место на диске.** На диске с репозиторием свободно не меньше 15 ГБ.

## Шаг 2. Забери свежий код

В папке `<репозиторий>`:

```
git status --short
git pull --ff-only origin main
git log --oneline -1
```

- Если `git status --short` показал изменённые файлы, ничего не откатывай: покажи список владельцу и спроси.
- Если `git pull` не прошёл, покажи ошибку владельцу.
- Запиши хеш последнего коммита, он нужен в отчёте.

## Шаг 3. Предупреди владельца и запусти замеры

Сначала скажи владельцу:

- **Что будет.** 16 прогонов подряд. Каждый открывает окно игры 1920 × 1080 и закрывается сам.
- **Сколько это займёт.** Точно неизвестно: на видеокарте проект ещё не запускался. Сборка — несколько минут. Первый прогон самый долгий, потому что движок компилирует шейдеры. Остальные — примерно по минуте. Зависший прогон скрипт сам снимает через 30 минут.
- **Как себя вести.** Во время прогонов лучше не нагружать машину и не щёлкать по окну игры: это искажает замеры. Каждое окно выходит на передний план. Захват мыши в проекте отключён настройкой, но на видеокарте это ещё не проверялось: если курсор всё же застрянет в окне, его освобождает Alt+Tab.
- **Что уйдёт в git.** Папка `prototype\results\ue5_<дата>_<имя компьютера>`: в названии папки и в сообщении коммита будет имя этого компьютера.

Дождись согласия владельца. Потом запусти из папки `<репозиторий>` одну команду и жди, пока она закончится:

```
powershell -NoProfile -ExecutionPolicy Bypass -File prototype\ue5\run_bench.ps1 -Engine "<движок>" -Commit
```

Команда работает долго и подолгу ничего не печатает. Это нормально. Не прерывай её. Если твой инструмент ограничивает время команды, запусти её в фоне и проверяй, жив ли процесс `powershell` с `run_bench.ps1`.

В конце она печатает строку `results: <папка>`. Эта папка дальше называется `<результаты>`.

## Шаг 4. Проверь результат

1. **Сводка.** Открой `<результаты>\summary-all.txt`. В ней должно быть:
   - первая строка `power plan: ...`;
   - 16 разделов, каждый начинается с `== <сценарий>_<здание>_c<число>`;
   - в каждом разделе строка `finished: scenario over`;
   - в каждом разделе строка `GPU:` с названием видеокарты, а не `(Null)`;
   - в каждом разделе строка `the same steps back to back before the run`, которая кончается на `(equal)`.
2. **Плохие признаки.** Перечисли владельцу все разделы, где есть хоть одно из этого:
   - `killed after 30 minutes`;
   - `no summary`;
   - `finished: time limit` или `finished: unknown scenario`;
   - `(DIFFERENT)`.
3. **Снимки.** В папке каждого прогона должны лежать файлы `.jpg`. Если их нет нигде, скажи об этом.
4. **Git.** В папке `<репозиторий>`:

   ```
   git status -sb
   git log --oneline -1
   ```

   Последний коммит должен называться `prototype: Unreal 5 measurements on <имя компьютера>`, а первая строка `git status -sb` не должна содержать слова `ahead`. Если коммит есть, а `ahead` осталось, выполни `git push origin main` и покажи результат. Если коммита нет, покажи владельцу вывод скрипта.

## Шаг 5. Отчитайся владельцу

Коротко, по-русски:

- версия движка (с `PatchVersion`) и хеш коммита, на котором шёл прогон;
- схема питания из первой строки сводки;
- сколько прогонов из 16 прошло чисто и какие нет;
- для каждого чистого прогона одна строка из его раздела сводки: `frame, while collapsing` (время кадра, пока здание осыпается). Если её значения нулевые, как в сценарии `idle`, возьми `frame, all`;
- ушли ли результаты в git.

Цифры не толкуй и выводов о движке не делай: разбор результатов сделают на сервере сборки, когда заберут их из git.

## Если что-то пошло не так

| Что видно | Что делать |
|---|---|
| `no Unreal Engine 5 in ...` | Путь к движку неверный. Вернись к шагу 1, пункт 3 |
| `the build failed` | Покажи владельцу последние 60 строк вывода. Код не правь |
| Курсор застрял в окне игры | Скажи владельцу нажать Alt+Tab и сообщи об этом в отчёте |
| Прогон снят через 30 минут на первом же запуске | Скорее всего, не успели шейдеры. Спроси владельца, запускать ли заново с ключом `-MinutesPerRun 90` |
| Ошибка `git push` | Покажи её владельцу: нужен его вход в GitHub. Результаты при этом остаются в папке и в локальном коммите |
| Что-то другое | Остановись, покажи вывод, ничего не чини |

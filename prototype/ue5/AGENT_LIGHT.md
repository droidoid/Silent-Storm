# Задание для агента: съёмка света при обрушении

← [Прототип](../README.md) · [Задание на замеры](AGENT_RUN.md)

Ты работаешь на машине владельца проекта: Windows, RTX 3090, Unreal Engine 5.8. Нужно забрать свежий код, один раз запустить готовый скрипт съёмки и убедиться, что кадры ушли в git. Скрипт всё делает сам. Отвечай владельцу по-русски.

Игра дважды обрушит часть здания и сохранит каждый кадр вокруг обрушения. По этим кадрам на сервере сборки посчитают, мерцает ли свет и как быстро он успокаивается.

## Правила и подготовка

Открой соседний файл [AGENT_RUN.md](AGENT_RUN.md) и выполни из него:

- раздел «Чего делать нельзя» — он действует и здесь;
- «Шаг 1. Проверь, что всё на месте»;
- «Шаг 2. Забери свежий код».

Остальные шаги того файла не выполняй: дальше иди по этому.

## Шаг 3. Предупреди владельца и запусти съёмку

Сначала скажи владельцу:

- **Что будет.** Два прогона подряд в окне 1280 × 720. Каждый закрывается сам.
- **Как это выглядит.** Окно движется рывками, по нескольку кадров в секунду. Это нормально: каждый кадр ждёт, пока сохранится его файл.
- **Сколько это займёт.** Сборка — около минуты, если проект уже собирался. Каждый прогон — примерно минута. Точнее сказать нельзя: съёмка на видеокарте ещё не запускалась.
- **Что уйдёт в git.** Папка `prototype\results\ue5light_<дата>_<имя компьютера>`: около 160 кадров JPEG, порядка 15 МБ. В названии папки и в сообщении коммита будет имя этого компьютера.

Дождись согласия владельца. Потом запусти из папки `<репозиторий>` одну команду и жди, пока она закончится:

```
powershell -NoProfile -ExecutionPolicy Bypass -File prototype\ue5\run_bench.ps1 -Engine "<движок>" -Light -Commit
```

В конце она печатает строку `results: <папка>`. Эта папка дальше называется `<результаты>`.

## Шаг 4. Проверь результат

1. **Сводка.** В `<результаты>\summary-all.txt` должно быть:
   - первая строка `power plan: ...`;
   - два раздела: `== grenades_large_c4` и `== half_large_c4`;
   - в каждом строка `finished: scenario over`;
   - в каждом строка `GPU:` с названием видеокарты, а не `(Null)`.
2. **Кадры.** В папках `<результаты>\grenades_large_c4` и `<результаты>\half_large_c4` лежат файлы `light_000.jpg`, `light_001.jpg` и так далее. Сосчитай их в каждой папке: должно быть от 70 до 90. Файлов `.png` остаться не должно.
3. **Плохие признаки.** Скажи владельцу, если есть хоть одно из этого:
   - `killed after 30 minutes` или `no summary`;
   - `finished: time limit`;
   - кадров в папке меньше 70 или нет вовсе;
   - кадры есть, но все `.png`.
4. **Git.** В папке `<репозиторий>`:

   ```
   git status -sb
   git log --oneline -1
   ```

   Последний коммит должен называться `prototype: Unreal 5 light capture on <имя компьютера>`, а первая строка `git status -sb` не должна содержать слова `ahead`. Если коммит есть, а `ahead` осталось, выполни `git push origin main` и покажи результат. Если коммита нет, покажи владельцу вывод скрипта.

## Шаг 5. Отчитайся владельцу

Коротко, по-русски:

- хеш коммита, на котором шла съёмка, и хеш коммита с результатами;
- сколько кадров в каждой из двух папок;
- были ли плохие признаки из шага 4;
- ушли ли результаты в git.

Кадры не оценивай и выводов о свете не делай: это сделают на сервере сборки.

## Если что-то пошло не так

| Что видно | Что делать |
|---|---|
| `the build failed` | Покажи владельцу последние 60 строк вывода. Код не правь |
| Окно открылось, но кадров нет | Покажи владельцу содержимое папки прогона и файл `prototype\ue5\Saved\Logs\SSProto.log` (последние 60 строк) |
| Прогон идёт дольше 10 минут | Не прерывай: скрипт сам снимет его через 30 минут. Сообщи об этом в отчёте |
| Курсор застрял в окне игры | Скажи владельцу нажать Alt+Tab и сообщи об этом в отчёте |
| Ошибка `git push` | Покажи её владельцу: нужен его вход в GitHub |
| Что-то другое | Остановись, покажи вывод, ничего не чини |
